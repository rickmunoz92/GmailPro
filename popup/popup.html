Gmail Pro preferences
APPEARANCE

Apple Mail Mode

A cleaner macOS-inspired Gmail. Appearance changes save and apply immediately.

For three panes, choose Gmail Settings → Reading pane → Right of inbox. Gmail keeps control of pane resizing.

BROWSING

Automatic page changes

At either end of the list, keep scrolling until the indicator fills, or click Next/Previous page. Stop scrolling to stay and read. Each page replaces the current one; Gmail’s page arrows remain available.

Requires Apple Mail Mode with the reading pane on the right. Pauses during selection or editing. Save preferences to apply.

COMPOSE

Gmail floating composer

Open replies and forwards in Gmail’s own floating composer. Minimize, restore, and save drafts normally.

Save preferences to apply. If unavailable, Gmail’s inline editor stays usable. New Compose uses Gmail’s default.

MAC KEYBOARD

Keyboard shortcuts

Archives the selected conversations or the open conversation, just like Gmail’s Archive button.

Sends only the draft you’re editing. Replaces Gmail’s discard shortcut; turning this off restores that shortcut.

Undoes Gmail’s latest available action. While editing, ⌘Z still undoes text.

Uses the open conversation and your floating composer preferences. ⌘R still refreshes Gmail. Reply All replaces Chrome’s ⇧⌘R hard reload shortcut; turn it off to restore that shortcut.

New message: Gmail’s C shortcut works when Gmail keyboard shortcuts are on. Chrome reserves ⌘N for New Window.

Save preferences to apply. Active only in Gmail on Mac. Gmail’s E, Z and ⌘Enter shortcuts remain available.

Resets to 100% when you open another conversation.
